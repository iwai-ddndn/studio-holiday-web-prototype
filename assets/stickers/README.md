# ステッカー画像の置き場

実際の作品ステッカー（PNG）はこのフォルダに置く。

- **ファイル名**: `main.js` の `STICKERS` マニフェストの `file` と一致させる
  （例: `star.png`, `cat.png`, `ghost.png` …）。追加したい場合はマニフェストに1行足す。
- **形式**: 背景透過のPNG推奨。透過の輪郭に沿って白フチ＋影が自動で付く（diecut表示）。
- **白背景の画像（JPG等）もOK**: 透過が無い場合、外周から繋がる白（RGB≥235）を自動で透明化して輪郭を作る。背景が白以外・グラデの場合は事前に切り抜いておくこと。
- **縦横比は自由**: 長辺基準でスプライトに収まる。
- **サイズ**: 400px角程度で十分（表示上限 ~230px）。正方形でなくても `object-fit: contain` で収まる。
- PNGが無い間は `main.js` 内のSVGプレースホルダーが自動で表示される。
